# ocean_lab

Лабораторная работа 01 по прикладной статистике (ИТМО, Инфохимия).

Датасет: [CalCOFI](https://www.kaggle.com/datasets/sohier/calcofi), океанографические наблюдения у берегов Калифорнии с 1949 года (`bottle.csv` и `cast.csv`).

## Кто какой ноутбук делал

| Участник | Случайная величина | Ноутбук |
|----------|--------------------|---------|
| Сошкина Дарья | Растворённый кислород (O2ml_L) | [Lab01_oxygen_KTvD.ipynb](Lab01_oxygen_KTvD.ipynb) |
| Семьяннова Владислава | Температура воды (T_degC) | [Lab01_temperatur_KTvD.ipynb](Lab01_temperatur_KTvD.ipynb) |
| Ткаченко Егор | Солёность (Salnty) и генератор случайных чисел | [Lab01_Salinity_KTvD.ipynb](Lab01_Salinity_KTvD.ipynb) |

## Структура проекта

### Ноутбуки с результатами

- [Lab01_oxygen_KTvD.ipynb](Lab01_oxygen_KTvD.ipynb) — растворённый кислород (O2ml_L).
- [Lab01_temperatur_KTvD.ipynb](Lab01_temperatur_KTvD.ipynb) — температура воды (T_degC).
- [Lab01_Salinity_KTvD.ipynb](Lab01_Salinity_KTvD.ipynb) — солёность (Salnty).

В ноутбуках оставлены оглавления, пояснения, таблицы, графики, результаты выполнения и выводы. Исходный код ячеек вынесен в отдельный файл.

### Исходный код

- [Lab01_Code.py](Lab01_Code.py) — исходный код, собранный из трёх ноутбуков и сгруппированный по исследуемым величинам.

## Примечание

Для просмотра результатов открывайте соответствующий ноутбук. Для изучения исходного кода используйте `Lab01_Code.py`.
